Publishing

How it works

The dashboard loads the current data/news.json and prepares the updated version for you.

  1. Fill in or edit the story.
  2. If using a picture, choose it and download the prepared image.
  3. Upload that image into assets/news/ on GitHub.
  4. Preview the story and click Copy JSON.
  5. Open data/news.json on GitHub, edit it, replace the contents, paste and commit.

Security: no GitHub password or access token is stored in this page.
