How it works

This helper loads the current data/news.json, adds your new story at the top and creates the updated file contents.

  1. Fill in the article.
  2. Preview it below.
  3. Click Copy JSON.
  4. Open the current data/news.json file in GitHub.
  5. Use GitHub’s edit button, replace the contents, paste the copied JSON and click Commit changes.

Security: this page does not contain a GitHub password or access token.
